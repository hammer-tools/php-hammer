This inspection identifies pointless calls to empty parent methods.

Empty methods are usually created to indicate that an abstract method serves no purpose at a given inheritance level and will be implemented lower down — so calling them via parent::method() is unnecessary.

abstract class A {
    abstract function example();
}

class B extends A {
    function example() { /* literally nothing */ }
}

class C extends B {
    function example() {
        parent::example(); // why?
        /* doSomething() */
    }
}
